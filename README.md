# Real-Time Chat Application

A full-stack real-time chat application designed to provide seamless and instant communication between users. Built using React.js for the frontend and Node.js with Express.js for the backend, the application uses Socket.IO for real-time messaging and MongoDB Atlas for data storage.

## Features

- Real-time messaging using Socket.IO
- User authentication and authorization
- Secure password hashing with bcrypt
- JWT-based authentication
- MongoDB Atlas database integration
- Responsive user interface

## Tech Stack

**Frontend:** React.js

**Backend:** Node.js, Express.js

**Database:** MongoDB Atlas

**Real-Time Communication:** Socket.IO

**Authentication:** JWT, bcrypt

## Project Purpose

This project demonstrates practical full-stack web development concepts, including frontend development, backend API integration, database management, user authentication and real-time communication.

## Status

Developed as a web development project to gain practical experience in full-stack application development.
